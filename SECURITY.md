# Security policy

Calm AI handles sensitive mental-health data, so please report vulnerabilities
privately rather than opening a public issue.

Please include what you found, steps to reproduce, and the impact. Do not
access or modify other people's data while testing, and do not publish details
until a fix is available.

## Scope

Anything in this repository: the web app, the `/api/v1` and `/api/public`
routes, and the Supabase migrations (row-level security). Never include real
user data or secrets in a report.
